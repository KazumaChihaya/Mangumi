# まんぞうラブ｜全画面UIモックパッケージ

仕様書の画面・状態・モーダル・共通部品の計204管理項目から、**合計299枚の個別画像**を出力しました。

- `images/member/` — 利用者向け **109枚**（860×1864 JPEG）
- `images/admin/pc/` — 運営管理PC版 **95枚**（1440×920 JPEG）
- `images/admin/mobile/` — 運営管理スマホ版 **95枚**（860×1864 JPEG）
- `references/` — 過去の画像生成コンセプト **29枚（重複のない元画像）**＋参考ビジュアル
- `sitemap/全画面サイトマップ.md` — 階層構造・相対リンク
- `sitemap/全画像一覧.csv` — 画面ID・段階・元画像・新画像の台帳
- `sitemap/仕様書_original.txt` 相当 — `sitemap/specification.txt` に依頼元仕様のテキスト
- `index.html` — ブラウザで開くプレビューギャラリー（画像検索／カテゴリ切替）
- `assets/` — モックで利用した素材画像

## 重要

**今回新たに作成した299枚は、HTML/CSSレイアウトから書き出した「UIデザイン画像」です。** 1枚ずつ画像生成AIに描いてもらったものではありません。代わりに各画面の文字・入力欄・グリッドなどを明確に表示し、仕様書の画面名と合わせて比較できるようにしています。従来のAI生成コンセプト画像は別フォルダで保存しています。

決済、ガチャ、プラン等について仕様を尊重しています。ガチャは**無料チケットでの抽選（有料コイン残高なし）**、投げ銭は**1回ごとの都度決済**、配信視聴は**YouTube外部リンク**を想定。ストーリー・スペース・DM・有料機能は段階公開です。

画像はあくまで静止画モックで、アニメーション・効果音・画面遷移・実際の操作・管理画面の動作は含まれません。画面中の日時・料金・利用者・統計はデザイン用サンプルです。正式な利用規約・プライバシーポリシーの条文は含みません。
