# 提供資料の保存範囲

このフォルダには、当初添付されたUI案の構成資料、サンプル一覧、素材を保存しています。元のREADMEやHTMLギャラリーは個別299枚の画像に言及していますが、当初の添付ZIPにはその個別画像が含まれていません。

再提供されたDriveの完全版は、ローカルの `.local/references/ui-full/` に展開しています。雰囲気画像29枚は `.local/references/mood/` にあります。大きな資料ZIPと全画像の複製をリポジトリへ追加せず、実装で使用する素材のみを `apps/member/public/assets/` に配置しています。

実装された全204項目の確認は、アプリの `/screens` を使用してください。レイアウトの根拠と雰囲気の根拠の区別は、[UI実装メモ](../ui-implementation.md) に記載しています。
