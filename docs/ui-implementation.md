## 構成と見た目の資料

- [UI案.zip](https://drive.google.com/file/d/1F6FH1T42dp3oL4U3JKUlOfizMGddTNDJ/view)：画面構成・サイトマップの根拠。
- [雰囲気イメージ.zip](https://drive.google.com/file/d/1p5RTm8vqqdyCZJSG_iddc_FGokCEVDPW/view)：全ページのビジュアルの基準。

雰囲気イメージには29枚のPNGがあり、UI案のreferences内にも同一の29枚が含まれていることをSHA-256で確認しました。UI案の静的画面の落ち着いた装飾ではなく、雰囲気画像の強い金属感、金色、赤、紫・青・ピンクのネオン、筐体の縁、ランプを共通テーマにしています。

構成資料のCSVは、当初添付されたUI案とDrive上の完全版でSHA-256が一致しました。利用者U001〜U109、管理A001〜A095の全204項目を `src/screens.json` に登録しています。画像枚数299は管理画面のPC・スマホ版を別々に数えた値で、ルートの管理項目は204です。

## 全ページの共通構成

利用者は共通のアートヘッダー、会員プラン表示、金属フレーム、ナビゲーションを使用します。管理者は共通のアートバナー、金属フレーム、管理メニュー、カテゴリ内タブを使用します。フォーム、確認、空状態、エラー、履歴にも同じ装飾を適用しています。

`global.css` と `cabinet.css` をレイアウト基盤とし、`jackpot.css` が全ページの強い筐体演出を共通化します。金属フレームは透明PNGの9分割border-imageで伸縮し、文字・フォーム・操作はDOMで利用できます。提供画像を参照するヘッダーのプラン表示は、プレビューの現在のプランで上書きします。[素材・生成プロンプトと見直し内容](pachislot-visual-update.md)を記録しています。

## 動作するUI

登録フロー、メール確認のプレビュー、プロフィール編集、画像アップロード・正方形への切り抜き、予定の月／週／一覧、通知設定、ストーリー既読、スペース参加・退出、ミニプレイヤー、テキストDM、端末上の音声録音、取消、通報、ブロック、支払い確認、プラン比較、無料チケット抽選、コレクション、ヘルプ、退会の画面を接続しています。

管理画面は一覧、フォーム、対象選択、確認、履歴を機能別に実装しています。予定・お知らせ・ストーリー・ブランド等の変更は同じセッションの利用者画面で確認できます。通報には対象時点のメッセージを証拠としてコピーし、運営画面から確認できます。

無料ガチャは暗号学的乱数を使い、チケット残高を確認してから消費・付与を一度に行います。二重クリックで複数回処理しないよう、実行中のガードと確認ダイアログを保持します。これはUIの操作検証用の抽選であり、実景品の付与ではありません。

確率変更は合計100%を検証し、前の確率テーブルを履歴に保存して新しいバージョンを作成します。抽選結果は抽選時のバージョンと景品名を保持します。個別結果の編集を提供せず、補填は別の付与履歴として記録します。

管理操作は、対象、理由、変更されたデータの前後、日時をプレビューの監査ログへ記録します。CSVは式として解釈され得るセルを無害化して出力します。UIプレビューには監査ログ削除の操作を設けていません。

## PWAと演出

Service Workerは公開画像・アイコンとオフライン案内のみをキャッシュします。認証、DM、決済、抽選結果、個人向け画面のHTMLをキャッシュしません。

効果音は初期OFFで、ONの操作後にWeb Audioを使用します。リール、ランプ、光沢、波形、紙吹雪はCSSで動作し、OSの動きを減らす設定とアプリの「演出ひかえめ」を尊重します。マイクの許可は録音・マイク確認のボタンを押した場合のみ要求し、画面離脱や録音停止時にトラックを終了します。

現在の画面はWeb用DOMの描画です。iOS・Android版はPhase 6として、共有データモデル・操作ロジックへネイティブ描画・通知・ストア課金のアダプターを追加します。
